Alcance y límites

Se mide el código funcional completo de src/, server/ y shared/. Solo se excluyen src/main.jsx y server/index.js, que arrancan React y el servidor. El arranque se comprueba mediante build y navegador. Configuración, CSS, dependencias, tests y herramientas de desarrollo no forman parte del porcentaje.

Los tests cubren validación fiscal, tarifas e impuestos, persistencia, límites y errores HTTP, origen/host, rate limit, consultas parametrizadas, XSS en renderizado, errores de red, cancelación, formularios, histórico y divisas. El navegador comprueba acciones y diseños a 320, 390, 768 y 1440 px. Se usan fixtures aislados y no datos reales de clientes.

100% de cobertura indica ejecución de las instrucciones y ramas medidas; no certifica ausencia de defectos ni sustituye auditorías de seguridad, autorización o pruebas de penetración. Los límites de despliegue y los avisos de dependencias se documentan en README y ai-workspace.
